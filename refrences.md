# References

## Moodle

- [Moodle External Services](https://moodledev.io/docs/4.5/apis/subsystems/external)
  explains Moodle's web-service framework and links to site-specific API
  documentation.
- Site-specific function and parameter documentation is available in Moodle under
  **Site administration → Server → Web services → API Documentation**.
- [Moodle Web Services Security](https://moodledev.io/docs/4.5/apis/subsystems/external/security)
  covers access control and token security for external services.

## Python and dependencies

- [Python virtual environments](https://docs.python.org/3/library/venv.html)
  describes creating and using the project's `.venv` environment.
- [Python `tomllib`](https://docs.python.org/3/library/tomllib.html) documents
  the standard-library TOML parser used for `config.toml`.
- [Requests quickstart](https://requests.readthedocs.io/en/latest/user/quickstart/)
  documents the HTTP client used for REST requests.
- [PEP 8](https://peps.python.org/pep-0008/) is the Python style guide followed
  by this project.
